# キットの部品とセンサ

キットの部品の一覧は [部品一覧](../parts.html) にあります。ここでは、IoT 設計制作実験で使えそうな部品の使い方をまとめます。

## ESP32 のピンの使い方

前の2回の回路で使っているピンと、ここで紹介する部品の標準のピンです。重ならないように選んでください。

| ピン | 使っているもの |
|---|---|
| IO34 | 力センサ(ADC1 チャンネル6) |
| IO5、IO17、IO16 | モータードライバ TB6612FNG(AIN1、AIN2、PWMA) |
| IO12〜IO15 | JTAG デバッガ(FT232H)。**他の用途に使わない** |
| IO25、IO26、IO27、IO33 | 9 軸センサ MPU-9250(SPI) |
| IO25、IO26、IO22 | D 級アンプ MAX98357A(I2S)。**MPU-9250 と同時に使うときは、どちらかのピンを変える** |
| IO0、IO2 | 起動のしかたを決めるピン(ストラッピングピン)。外付けの回路で引っ張らない |
| IO6〜IO11 | フラッシュメモリ用。使えない |

ADC で電圧を読むなら IO32〜IO39(ADC1)を使います。ADC2 のピンは、無線LAN を使っている間は使えません。

## 9 軸慣性センサ MPU-9250

加速度センサ・ジャイロ(角速度)・地磁気センサが入っています。[データシート](https://cdn.sparkfun.com/assets/learn_tutorials/5/5/0/MPU9250REV1.0.pdf)・[レジスタマップ](https://cdn.sparkfun.com/assets/learn_tutorials/5/5/0/MPU-9250-Register-Map.pdf)(TDK InvenSense の資料。生産終了のためメーカーのページは無くなっており、SparkFun に置かれているものを参照)

**配線**(センサのピン名は基板の**裏面**に書いてあります)

| センサ | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCLK | IO27 |
| SDI | IO26 |
| SDO | IO25 |
| NCS | IO33 |

**サンプル**: [`firmware/Mpu9250`](https://github.com/hasevr/ICTEx5/tree/main/firmware/Mpu9250)(ESP-IDF v5.5、SPI で加速度と角速度を 10 Hz で表示)。
ノートブックで `cp -r /content/work/ictex5/firmware/Mpu9250 /content/work/` としてコピーし、ビルドして書き込みます。
うまくいけば、次のように表示され、センサを傾けたり振ったりすると数値が変わります。

```
WHO_AM_I = 0x71 (MPU-9250)
accel: [ -0.99  +0.09  +0.12] G   gyro: [   +5.72    -1.57    +1.91] deg/s
```

`WHO_AM_I` が `0x00` や `0xFF` なら配線を確かめてください。地磁気センサ(AK8963)はセンサの内部の I2C の先にあり、このサンプルでは読んでいません。
使うときは、AI に「MPU-9250 の内部の I2C マスタを使って AK8963 を読むように」と頼みます。

{: .note }
前年度までの資料で使っていた ESP32 MPU Driver などのライブラリは、ESP-IDF v4 用で、今の環境ではそのままでは使えません。

## エレクトレットコンデンサーマイクロホン

[秋月電子の商品ページ](https://akizukidenshi.com/catalog/g/gP-08182/)(データシートもここから)

マイクの中にアンプ(FET)があるので、抵抗を通して電源を与えて使います。

```
3V3 ── RL(2.2 kΩ 程度)──┬── マイクの + 側
                          └── ESP32 の ADC1 のピン(例: IO35)
GND ───────────────────────── マイクの − 側(ケースにつながっている方)
```

コンデンサは付けずに、ADC に直結するのが簡単です(信号は 1.5 V 前後を中心に小さく揺れます)。
音の大きさを測るなら、ADC を数 kHz 以上で読み、平均との差の大きさ(実効値)を計算します。AI には「何 Hz で読み、何を計算するか」を具体的に伝えてください。

## D 級アンプ MAX98357A

スピーカーや振動子を、音声と同じ I2S で駆動できます。回路とファームウェアは [D 級アンプで駆動する](../haptics/i2s.html) にあります。
**電源は 3.3 V、出力に 10 Ω を直列に**(USB の電流の上限を超えないため)。

## その他のキットの部品

- **フォトリフレクタ**: 近くの物の有無や、白黒の模様を読む。赤外線 LED と受光部がセットで、受光側を抵抗で引いて ADC で読む。
- **スピーカー(8 Ω)**: D 級アンプでつなぐ。
- **モータ・力センサ**: 触覚提示実験の回路のまま使える。

## ESP32 の便利な機能

- **タッチセンサ**: 静電容量を測れるので、電線や金属板をそのままタッチセンサにできる([ESP-IDF の説明](https://docs.espressif.com/projects/esp-idf/en/v5.5.1/esp32/api-reference/peripherals/cap_touch_sens.html))。
- **Bluetooth LE**: スマートフォンとつなぐ、ビーコンを作る。
- **ESP-NOW**: 無線LAN のアクセスポイントを使わずに、ESP32 どうしで直接やりとりする。
- **電波強度(RSSI)**: 無線LAN や BLE の電波の強さ。距離の目安になる(Wi-Fi による位置推定は [暦本研究室の PlaceEngine](https://lab.rekimoto.org/projects/placeengine/) が先駆け)。

## 追加の部品

温湿度・気圧センサ(BME280)のモジュールが少しあります。使いたいグループは教員・TA に相談してください。
