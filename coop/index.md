# 組み込みマイコンボードの協調動作実験

## 目的

- 無線LAN 上で HTTP を使って通信し、センサノード(ESP32)からサーバ(Raspberry Pi)に情報を集める方法を知る。
- サーバからセンサノードに指示を送り返し、2つのマイコンボードを協調して動かす方法を知る。
- 通信の間隔・遅れ・データ量を**実際に測り**、次回からの IoT 設計制作実験で仕様を決める手がかりにする。

## 概要

触覚提示実験で作った ActiveHaptic(押すとモータが振動する)に、無線LAN の通信を加えた **HttpHaptic** を ESP32 で動かします。
ESP32 は力センサの値を Raspberry Pi の Web サーバに送り、サーバはそれを記録してブラウザにグラフで表示します。
ブラウザから振動の周波数を入力すると、サーバが ESP32 への応答に入れて送り返し、モータの振動が変わります。

```
ESP32 (HttpHaptic)                      Raspberry Pi (app.py, :50000)
   |                                       |
   |-- GET /getadc?ADC=1975&TIME=12.3 ---->|  記録する
   |<----- {"adc": 1975, "freq": 200} -----|  周波数を返す
   |                                       |
 Wi-Fi: ICT_EX5_2G                   有線LAN(ハブ)
                                           |
                         PC のブラウザ ----+  グラフ・周波数の入力
```

ESP32 のプログラムも Raspberry Pi のプログラムも、触覚提示実験と同じく **Colab の AI(またはあなた自身)が書き換えます。**
ESP32 への書き込みは ESP32 ブリッジで、Raspberry Pi へは PC から `scp` で送ります。

## 準備と手順

この実験は**個人ごと**に行います(班での議論もあります)。
**1回(3時間)で実験まで終えます。** 目安は、前半の1時間半で 1 を済ませて一通り動かし、後半の1時間半で 2 の実験をします。

1. [準備と動作確認](setup.html) — 前半の1時間半。Raspberry Pi の SD カードを作って起動し、サーバを動かし、ESP32 に HttpHaptic を書き込んで、
   力センサの値がブラウザのグラフに出るところまで。
2. [協調動作の実験](experiment.html) — 後半の1時間半。レポート課題を含む。
   レポートは実験のあと、**次週までに** LMS に個人ごとに提出する。

## AI と人の分担

| | AI(Antigravity CLI) | 人 |
|---|---|---|
| プログラム | ESP32 と Raspberry Pi の両方のプログラムを読む・書き換える・ビルドする・書き込む | 何を作るか決める、AI の変更を読んで確認する、小さな変更は自分で書き換える |
| 実機 | `esp log` で ESP32 の出力を読む | SD カードを作り Raspberry Pi を起動してサーバを動かす、プログラムを Raspberry Pi に送る、書き込みを承認する |
| 評価 | 測った値の集計・グラフ化 | **通信の間隔・遅れを測る、触って確かめる**、実験条件をそろえる |
| レポート | 変更点の要約、調べ物の手伝い | 考察を自分の言葉で書く |

AI は Raspberry Pi や実験室のネットワークに直接は触れません(Colab はインターネットの向こうにあるため)。
Raspberry Pi 上で起きていること(サーバの出力、届いた値)は、あなたが見て AI に伝えてください。

## 前年度までとの違い

- Raspberry Pi の SD カードには、この実験用に設定済みの最新の Raspberry Pi OS のイメージを、設定なしで書き込みます。起動するとディスプレイに IP アドレスが出るので、キーボードはつながず、PC から SSH で操作します(OS の更新やソフトウェアの追加は不要)。
- ESP32 の開発は、触覚提示実験と同じ Colab の環境で行います(VSCode は不要)。
- サーバの宛先(Raspberry Pi の IP アドレス)は、プログラムを書き換えずにシリアルのコマンドで設定できます。
- 前年度の実験5(Raspberry Pi から ESP32 への周波数の指示)までを、最初のサンプルに入れてあります。
  実験では、その仕組みを測り、改良することに時間を使います。
